# 과학 임용 학습교재

[프로젝트 소개](../README.md) · [범위 선택 화면](https://www.5e.ai.kr/print/?source=imyong) · [제작 규칙](../SKILL.md)

## 먼저 알아둘 범위

물리·화학·생물·지구과학의 2002–2026학년도 기출 2,588문항을 색인합니다. 과학교육론은 네 과목 안의 문항 영역입니다. 기본 교재 범위는 최근 10개 학년도인 **2017–2026**, 총배점이 확인되는 **2점·4점**입니다.

원문 PDF의 수식·그림·글자를 재사용합니다. 배점은 원문의 총점을 따르며 소문항 배점을 합산해 추정하지 않습니다. 원본은 수정하지 않습니다.

## 화면에서 범위 고르기

- 과목·영역, 시작·끝 학년도, 2점/4점, 전공 A/B를 고릅니다.
- 단원·세부 주제를 여러 개 고르거나 본문 검색과 제외어로 좁힙니다.
- 일치 문항 수와 예시를 보고 최대 문항 수·정렬·무작위 번호를 정합니다.
- 용지·여백·제목·해설 요청을 정한 뒤 제작 요청을 복사합니다.

30개 단원·72개 세부 주제는 원문 용어에 따른 자동 분류이며 공식 확정 분류가 아닙니다. 복수 주제는 OR, 그 외 범위와 검색 조건은 AND입니다. 경계 문항은 본문 검색과 미분류도 확인합니다. 같은 문항에 여러 태그가 있어도 한 번만 수록합니다.

## 설정 JSON으로 재현하기

화면의 제작 요청에 포함된 설정을 JSON 파일로 저장해 사용합니다. 다음은 물리 양자역학 두 주제에서 같은 번호로 8문항을 고르는 예입니다.

```json
{
  "subject": ["t_physics"],
  "domain": "",
  "yearFrom": 2017,
  "yearTo": 2026,
  "points": [2, 4],
  "topicIds": [
    "t_physics.quantum.operators",
    "t_physics.quantum.applications"
  ],
  "keywords": "",
  "excludeKeywords": "",
  "paperPart": "",
  "questionLimit": 8,
  "sortMode": "random",
  "seed": "5e",
  "memoStyle": "grid",
  "paper": "A3",
  "title": "양자역학 복습"
}
```

| 설정 | 값 |
| --- | --- |
| `subject` | `t_physics`, `t_chemistry`, `t_biology`, `t_earth`의 배열. 빈 배열은 네 과목 전체 |
| `domain` | 빈 문자열(전체), `content`, `pedagogy` |
| `yearFrom` · `yearTo` | 시작·끝 학년도 |
| `points` | `[2]`, `[4]`, `[2, 4]` |
| `topicIds` | 주제 ID 배열. 빈 배열은 주제 제한 없음. [분류표](../data/imyong-topics.json) 참고 |
| `keywords` | 최대 세 단어 AND 본문 검색 |
| `excludeKeywords` | 포함되면 제외할 단어. 여러 단어 중 하나라도 일치하면 제외 |
| `paperPart` | 빈 문자열(전체), `A`, `B` |
| `questionLimit` | 0은 조건에 맞는 전체. 1–2,588은 최대 문항 수 |
| `sortMode` | `recent`, `oldest`, `topic`, `random` |
| `seed` | 같은 데이터·조건에서 무작위 문항과 순서를 재현하는 문자열 |
| `memoStyle` | `blank`, `ruled`, `grid` |
| `paper` | `A3` 가로, `B4`·`A4` 세로 |
| `title` | 사용자 제목. 빈 문자열은 범위로 생성 |

문항 수는 선택·정렬 뒤 제한하고 **배점별로 묶어 배치**합니다. 따라서 무작위도 2점과 4점을 번갈아 배치하지는 않습니다. 줄·모눈은 원문 아래의 남는 풀이 공간에만 넣습니다.

```bash
python3 scripts/build_imyong_book.py \
  --config /path/to/work/임용-설정.json \
  --output /path/to/materials/양자역학_학습지_v1.pdf \
  --cache /path/to/work/pdf-cache
```

로컬 공유 원본을 쓰려면 `--source-root /path/to/shared-folder`를 추가합니다. 이 폴더 아래 `기출문제/임용기출/…` 경로를 읽습니다. 의존성은 [설치 안내](DEVELOPMENT.md)에 있습니다. 전체 옵션은 `python3 scripts/build_imyong_book.py --help`로 확인합니다.

## 생성 파일

| 파일 | 내용 |
| --- | --- |
| `이름.pdf` | 문제편. 2점 4문항/쪽, 4점 2문항/쪽 |
| `이름_원문확대본.pdf` | 축소율 기준 미만인 긴 문항의 원래 시험지 쪽. 해당 문항이 있을 때 생성 |
| `이름.json` | 문항 ID·총배점 근거·출처·원문 영역·본책 쪽·칸·축소율·확대본 쪽·주제 근거·제작 설정 |

CLI는 JSON 문항표를 만듭니다. 사용자용 XLSX는 이 자료로 별도 작성하며, 공개된 전체 범위 교재에는 완성 XLSX를 함께 제공합니다. 임용 교재는 기존 Typst 편집기 대신 설정 JSON으로 재생성합니다.

확대본에는 같은 시험지 쪽의 다른 문항이 함께 보일 수 있습니다. 각 배점의 마지막 쪽은 남는 칸을 풀이 공간으로 둡니다. 기존 결과는 덮어쓰지 말고 파일 판을 올리세요. `--overwrite`는 배포하지 않은 작업 중 초안에만 사용합니다.

## 해설과 필요한 개념

**현재 공개 문제편과 원문 합성 CLI는 정답·해설·개념 정리를 포함하지 않습니다.** 화면에서 고른 해설 옵션은 AI의 별도 작성·대조 단계로 전달합니다.

해설을 추가할 때는 원문을 다시 풀고 실제 참고 자료와 대조 상태를 기록합니다. AI 작성 초안을 공식 해설이나 검증 완료 정답으로 표시하지 않습니다. 개념은 해당 문항을 푸는 데 필요한 부분만 정리합니다. 자료가 없는 답을 검증된 것으로 채우지 않습니다.
